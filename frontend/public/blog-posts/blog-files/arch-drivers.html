How to install rtl8812au driver and nvidia driver on Arch Linux

This blog post covers how to install the rtl8812au driver and nvidia driver on Arch Linux using yay.

Install rtl8812au driver

  • Install using yay: 
    yay -S rtl8812au-dkms-git
  • Unplug and replug the adapter
  • Check network interfaces: 
    ip link
  • If the interface shows up as "down" do: 
    ip link set [interface name] up

Install nvidia driver

  • Look on archlinux nvidia documentation
  • Install driver using yay: 
    yay -S nvidia
